# Оптимизация SQL-запросов в PostgreSQL

## О проекте
Пет-проект сделан с целью продемонстрировать навыки анализа и оптимизации запросов к базе данных. В рамках работы смоделированы данные по пользователям из 10 тыс. строк и заказам из 1 млн строк и произведён анализ производительности запроса с JOIN и фильтрацией с использованием индексирования и без. 

## Стек технологий
- PostgreSQL
- DBeaver
- Git/GitHub

## Проблема
Исходный запрос фильтрации данных по дате и пользователю без использования индексов выполнялся построчно по таблице: анализ плана выполнения - EXPLAIN ANALYZE - показал, что СУБД использовала **'Seq Scan'**, и время выполнения составило около **337 мс**. 

## Решение
Для оптимизации были созданы B-tree индексы:
- на колонку 'user_name',
- на колонку 'user_id',
- на колонку 'created_at'.

## Результат.
Время выполнения запроса сократилось до примерно **0.19 мс**. План выполнения изменился на **'Index Scan'** и **'Bitmap Index Scan'**.

## Структура проекта. 
- sql_scripts - папка со скриптами
  - tables.sql -создание таблиц и генерация данных
  - query.sql - запрос
  - indexes.sql - создание индексов
